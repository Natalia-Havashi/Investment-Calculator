# 💰 React Investment Calculator

This is a web application built with React that allows users to calculate how their investments grow over time, based on initial amount, yearly contributions, and expected return rate.

## 🚀 Live Demo

🔗 [View on GitHub Pages](https://natalia-havashi.github.io/Investment-Calculator/)

## ✨ Features

- Input initial investment amount
- Set annual contributions
- Choose expected annual return rate
- Define investment duration in years
- See year-by-year breakdown including:
  - Investment value
  - Interest earned
  - Total interest
  - Invested capital

## 🛠 Technologies Used

- React 19
- Vite
- GitHub Pages for deployment
- ESLint for code linting
